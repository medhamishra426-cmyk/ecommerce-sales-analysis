# E-commerce Sales Analysis

A data analysis project on 100 e-commerce orders from 1 January to 9 April 2024. It loads, cleans, validates, analyses, and visualises the data, then summarises the findings.

**Questions answered:**
- Which products generate the most revenue?
- Which regions perform best?
- How does revenue change month to month?

---

## Dataset

File: `data/sales_data.csv` (100 rows, 7 columns)

| Column | Description |
|---|---|
| Date | Order date (YYYY-MM-DD) |
| Product | Laptop, Tablet, Phone, Headphones, or Monitor |
| Quantity | Units per order (1 to 9) |
| Price | Unit price |
| Customer_ID | Customer identifier (one order per customer) |
| Region | North, South, East, or West |
| Total_Sales | Quantity × Price |

## Code Structure

```
ecommerce-sales-analysis/
├── README.md              Project overview and documentation
├── analysis.ipynb         Full pipeline: load → clean → analyse → visualise → export
├── requirements.txt       Python dependencies
├── data/
│   ├── sales_data.csv     Raw input data
│   └── sales_cleaned.csv  Cleaned output (generated by the notebook)
├── visualizations/        Charts saved by the notebook
└── report/
    ├── report.md          Full written report with insights
    └── revenue_by_product.csv
```

The notebook follows five stages:

1. **Load:** reads the CSV and checks that all required columns exist.
2. **Clean:** removes duplicates, converts types, drops invalid rows, and validates that `Total_Sales = Quantity × Price`.
3. **Analyse:** calculates totals, product and region breakdowns, and monthly trends.
4. **Visualise:** creates and saves three charts.
5. **Export:** saves the cleaned data and summary tables.

## Key Findings

- **Total revenue:** 12.37 million across 100 orders, with 478 units sold. Average order value is about 123,650.
- **Laptops lead** with 31.5% of revenue (3.89M from 24 orders). Tablets (23.3%) and phones (23.1%) follow.
- **North (32.2%) and South (30.2%)** generate most of the revenue. East (20.4%) and West (17.2%) trail.
- **Monthly revenue is volatile:** January 4.12M, February 2.66M (down about 36%), March 4.49M (up about 69%).
- **April is partial:** it covers only 1 to 9 April, so it should not be compared with full months.

Full analysis in [`report/report.md`](report/report.md).

## Limitations

- **Price variation is unrealistic.** The same product sells at prices that differ about tenfold (for example, headphones range from 4,195 to 49,930). This suggests the data is synthetic, so the findings demonstrate the method rather than real business performance.
- **No repeat customers.** Each of the 100 customer IDs appears once, so retention and repeat-purchase analysis is not possible.
- **No currency.** Values are reported in millions without a currency symbol.
- **Short period.** Only about three months of data, with April incomplete.
